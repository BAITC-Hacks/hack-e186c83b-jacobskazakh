# AI Sana Challenge Hub

AI Sana Challenge Hub помогает компаниям превращать краткие описания бизнес-проблем в понятные проектные задачи, а студентам — находить их и предлагать решения.

## Проблема

Компаниям бывает трудно сформулировать задачу так, чтобы студенческая команда понимала цель, ожидаемый результат, сроки и доступные ресурсы. Из-за этого полезные проекты остаются неопределёнными, а студентам сложно выбрать задачу и подготовить содержательный отклик.

## Решение

Hub проводит пользователя через создание структурированной карточки задачи, оценивает её готовность к публикации и собирает отклики студентов в одном месте. AI предлагает пять уточняющих вопросов по черновику. Если API недоступен или ключ не задан, приложение использует встроенный список вопросов.

## Возможности

- Создание карточки с целью, ожидаемым результатом, навыками, сроками и ресурсами.
- Оценка готовности карточки по заполненности пяти ключевых полей.
- Каталог опубликованных задач с фильтром по теме и минимальной готовности.
- Отклик команды с идеей, планом и необязательной ссылкой на материалы.
- Просмотр откликов владельцем задачи и изменение статуса решения.
- Генерация уточняющих вопросов через OpenAI API с резервным сценарием без API.

## Основной сценарий демо

1. На вкладке «Новая задача» введите описание бизнес-проблемы и получите уточняющие вопросы.
2. Заполните название, компанию, цель, результат и другие поля карточки.
3. Проверьте оценку готовности и опубликуйте задачу.
4. Откройте «Каталог», найдите опубликованную задачу и отправьте отклик с идеей и планом.
5. На вкладке «Отклики» просмотрите предложение и измените его статус.

## Технологии

- Python и Streamlit — веб-интерфейс.
- SQLite — хранение задач и откликов.
- OpenAI API — генерация уточняющих вопросов (необязательно).
- `python-dotenv` — загрузка локальных переменных окружения.

## Запуск локально

Нужен Python 3.10 или новее.

```bash
python -m venv .venv
```

Активируйте виртуальное окружение, затем установите зависимости и запустите приложение:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Приложение откроется в браузере по адресу, который выведет Streamlit (обычно `http://localhost:8501`). Без API-ключа генерация работает на встроенных вопросах.

### Включить генерацию вопросов через OpenAI

Скопируйте `.env.example` в `.env` и укажите ключ в `.env`:

```dotenv
OPENAI_API_KEY=ваш_ключ
```

Не добавляйте `.env` в Git. Ключ не требуется для локального запуска базового сценария.

## Данные

По умолчанию приложение создаёт SQLite-базу `challenge_hub.db` в рабочей папке. Файл базы и локальные секреты исключены из Git. При необходимости путь к базе можно задать переменной `DATABASE_PATH` в локальном окружении.

## Структура проекта

- `app.py` — интерфейс, логика карточек, каталога и откликов.
- `requirements.txt` — зависимости Python.
- `.env.example` — пустой шаблон переменной ключа OpenAI.
